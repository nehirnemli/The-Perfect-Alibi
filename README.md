# THE PERFECT ALIBI
### CASE 001 — THE LAST EXHIBITION

**An interactive detective mystery created for NMED 3203: Interactive Media Applications.**

 **Live experience:** https://nehirnemli.github.io/The-Perfect-Alibi/

## About the Project

THE PERFECT ALIBI is a browser-based interactive mystery set during an invitation-only collectors' preview at an art gallery in İzmir. A valuable painting, *The Last Light*, has disappeared. Four people are connected to the incident, each with different motives and intentions.

The participant investigates the suspects, examines evidence, follows the timeline, and makes a final decision about who physically moved the painting.

## Interactive Premises

This project combines two interactive premises:

### 1. Agency
Participants actively investigate the case by exploring suspect profiles, reviewing evidence, and making their own final verdict. Their choices guide how they engage with the investigation.

### 2. Possibility
The evidence follows a sequential unlocking system. Reviewing one evidence file makes the next file available. This rule determines which actions are possible at each stage of the experience.

## How to Play

1. Open the live website.
2. Enter the case and read the briefing.
3. Explore the four suspect profiles.
4. Review the eight evidence files in sequence.
5. Follow the timeline as new information becomes available.
6. Once all evidence has been reviewed, submit your verdict.
7. Read the final case reveal.

**Note:** All evidence files must be reviewed before the final verdict becomes available.
